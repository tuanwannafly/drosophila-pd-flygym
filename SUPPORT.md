# Support

This repository is maintained as research software.

For actionable bugs or scoped implementation requests, open a GitHub issue.
For research planning, assay design, literature mapping, reproducibility notes,
or roadmap discussion, use GitHub Discussions if enabled for the repository.

Do not share private credentials, access tokens, unpublished data, or sensitive
local paths in public issues or discussions.

This project is not a medical device, diagnostic tool, or validated biological
Parkinson's disease model.
