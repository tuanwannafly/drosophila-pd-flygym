# Code of Conduct

## Our Pledge

We aim to make this repository a respectful, focused, and constructive research
software space. Participants are expected to communicate with care, assume good
faith, and keep criticism specific to ideas, code, documentation, or evidence.

## Expected Behavior

- Be respectful and professional.
- Keep discussions evidence-based and clear about uncertainty.
- Separate software behavior from scientific interpretation.
- Credit prior work and cite sources where relevant.
- Help maintain reproducibility and traceability.

## Unacceptable Behavior

- Harassment, intimidation, or discriminatory language.
- Personal attacks or sustained disruptive conduct.
- Misrepresenting simulation output as biological validation.
- Publishing private or sensitive information without permission.

## Enforcement

Project maintainers may moderate discussions, close issues, request edits, or
limit participation to keep the project safe and productive. Concerns can be
raised through GitHub issues, discussions, or repository maintainer channels.
