# Scientific Scope

The Session07/08 platform quantifies simulated behavior from existing arrays.
It supports computational assay design, exploratory visualization, and
controlled comparison reports.

It does not claim:

- Parkinson's disease validation
- dopamine equivalence
- disease severity mapping
- biological progression
- biological rescue
- mechanistic equivalence
- statistical significance

Terms such as Healthy, Candidate, Progression, and Intervention are caller
provided computational labels.
