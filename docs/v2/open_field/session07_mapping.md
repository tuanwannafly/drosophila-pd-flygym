# Session07 Mapping

Session07 is the open-field behavioral assay session.

Expected Session07 work:

- define rectangular, circular, and custom open-field arenas
- compute center occupancy, border occupancy, radial distance, heat maps,
  occupancy histograms, transition probability matrices, exploration entropy,
  coverage ratio, revisit frequency, path tortuosity, path curvature, dwell
  time, and zone transition graphs
- export open-field JSON/CSV reports
- generate dashboard panels for trajectory exploration and occupancy summaries

Session07 should not rerun simulations automatically or change perturbation
logic.
