# Configurable Score Scope

`computeParkinsonScore` is a configurable computational index. It accepts feature definitions with explicit reference, scale, direction, and weight values. It reports a weighted breakdown, confidence based on available configured features, and explainability metadata.

The implementation does not contain diagnostic thresholds or a default disease score. It does not measure dopamine, disease severity, mechanism, rescue, statistical significance, or biological Parkinson disease. Any future configuration must carry its own computational provenance and remain separate from frozen scientific evidence.
