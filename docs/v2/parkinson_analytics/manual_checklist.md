# Manual Checklist

- [ ] Import a normalized FlyGym rollout through the existing loader.
- [ ] Request a feature bundle and confirm availability reflects present channels.
- [ ] Confirm walking, turning, standing, grooming, and unknown segmentation labels are returned without browser errors.
- [ ] Inspect descriptive statistics, histogram, distribution, percentile, and trend outputs.
- [ ] Compare two or more computational conditions and inspect difference, correlation, similarity, distance, and ranking fields.
- [ ] Render trajectory, line, heatmap, and correlation SVG outputs.
- [ ] Render a canvas plot and export PNG.
- [ ] Export JSON, CSV, Markdown, HTML, and SVG analytics artifacts.
- [ ] Run a configured score with explicit references and confirm the report says computational index only.
- [ ] Confirm no simulation starts and no frozen evidence or manuscript files change.
