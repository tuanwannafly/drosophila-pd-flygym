## Synthetic Pipeline

```python
dataset = synthetic_behavior_dataset(sample_count=5, sample_length=24)
matrix = generate_feature_matrix(dataset)
embedding = pca_embedding(matrix["matrix"])

```

All samples generated by `synthetic_behavior_dataset()` include
`synthetic=True` and `scientific_evidence=False` metadata.
