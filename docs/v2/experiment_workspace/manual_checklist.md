# Manual Checklist

- [ ] Open `web/index.html` through a local or GitHub Pages server.
- [ ] Load a valid FlyGym-compatible JSON file.
- [ ] Confirm the experiment appears with its selected kind.
- [ ] Import a second rollout and select both records for comparison.
- [ ] Rename, clone, and delete a non-protected experiment.
- [ ] Confirm duplicate rollout imports are reported by dataset validation.
- [ ] Filter the experiment list and confirm dashboard row count changes.
- [ ] Export Markdown and CSV reports; use PDF to open the browser print dialog.
- [ ] Save and restore the workspace; confirm panel state and loaded experiment metadata return.
- [ ] Resize the browser and confirm panels remain usable.
- [ ] Confirm the browser console has no new JavaScript errors.
