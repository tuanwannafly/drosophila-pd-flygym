# Experiment Workspace Tutorial

1. Load a FlyGym-compatible JSON rollout with the existing **Load JSON** control.
2. Choose the computational kind when importing from the Experiments panel.
3. Use the experiment list to activate, rename, clone, or remove records.
4. Tick records to include them in the comparison selection.
5. Use the filter field and numeric filter API to restrict dataset rows.
6. Export Markdown or CSV from the panel. PDF output uses the browser print dialog.

The dashboard and reports summarize measured rollout channels only. A label in the experiment manager is not a biological diagnosis or validation statement.
