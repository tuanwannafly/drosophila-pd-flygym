# Manual Checklist

- [ ] Describe a finite numeric vector and inspect quartiles/percentiles/distribution.
- [ ] Run seeded bootstrap and jackknife and confirm repeatability.
- [ ] Run all hypothesis-test methods with two numeric groups.
- [ ] Compute all effect sizes and apply each multiple-comparison correction.
- [ ] Compute Pearson, Spearman, Kendall, partial correlation and a matrix.
- [ ] Fit linear, polynomial and robust regressions and inspect residuals.
- [ ] Run assumption, missing-data and outlier-sensitivity checks.
- [ ] Generate JSON, Markdown, HTML and CSV reports.
- [ ] Run the benchmark path and record local timing separately from scientific results.
- [ ] Confirm no rollout, evidence, simulation or UI file was modified.
