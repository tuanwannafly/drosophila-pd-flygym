# Methods

Implemented descriptive outputs include mean, median, population/sample variance, standard deviation, quartiles, percentiles, and histogram distributions.

Resampling includes seeded percentile bootstrap confidence intervals and jackknife estimates. Tests include Welch t-test, Mann-Whitney, Wilcoxon signed-rank, one/two-sample KS, and seeded permutation testing. Effect sizes include Cohen's d, Glass delta, Cliff delta, and rank-biserial output.

Corrections include Bonferroni, Holm, and Benjamini-Hochberg. Correlations include Pearson, Spearman, Kendall, partial correlation, and matrices. Regression includes linear, polynomial, robust IRLS, and residual summaries.

Some p-values use documented normal/asymptotic approximations and tie corrections are intentionally limited. Results must be reviewed against the data and assumptions before scientific interpretation.
