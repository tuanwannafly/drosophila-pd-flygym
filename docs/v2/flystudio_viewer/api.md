# API Reference

- `ViewerState`: Runtime boolean flags and timestamps.
- `ViewerLayout`: Viewport configuration templates.
- `ViewportController`: Local overrides for grid and skeleton visibility.
- `TimelinePanel`, `PlaybackPanel`: Control abstractions over `ViewerState`.
- `CameraPanel`: Predefined target locking and zoom.
- `SelectionPanel`: Track selected Scene Graph nodes.
- `StatisticsPanel`: Profiling readouts (FPS).
- `RecordingPanel`: Hooks for video export logic.
- `ViewerPreferences`: Global visual preferences.
- `ViewerEvents`: Event dispatch system.
- `ProjectWorkspace`: Active directory / project manifest holder.
- `ViewerSession`: Global application root object.
- `ViewerSerializer`: Session serializer.
