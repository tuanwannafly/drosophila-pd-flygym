# API Reference

- `App`: Initializes the global application singletons.
- `Viewer`: Manages HTML target containers for renderer injections.
- `Timeline`: Tracks time and controls playback.
- `Camera`: Manages viewing preset states.
- `JSONLoader`: `loadJSON(url)` fetches workspace configurations.
- `ProjectLoader`: Binds loaded JSON to the active workspace.
- `Workspace`: Global state repository.
- `Settings`: Handles CSS variable injections (`--bg-base`, etc.).
