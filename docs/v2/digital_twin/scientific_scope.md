# Scientific Scope

The digital twin platform stores and replays computational state. It supports
behavioral summaries, scenario records, virtual parameter interventions, and
visualization artifacts.

It does not claim:

- Parkinson's disease validation
- biological disease progression
- dopamine equivalence
- L-DOPA or pharmacological treatment modeling
- biological rescue
- disease severity mapping
- mechanistic equivalence
- statistical significance

Scenario roles and intervention names are computational labels supplied by the
caller.
