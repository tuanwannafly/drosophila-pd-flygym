# Session10 Mapping

Session10 is the virtual intervention, interactive laboratory, and scenario
session.

Expected Session10 work:

- define computational interventions as parameter modifications
- replay intervention schedules deterministically
- compare before/after computational reports
- build experiment catalogs and laboratory layouts
- manage Healthy, Candidate, Progression, Future Intervention, and custom
  scenarios
- export replay dashboards and synchronized visualization artifacts

Session10 interventions are computational parameter changes only.
