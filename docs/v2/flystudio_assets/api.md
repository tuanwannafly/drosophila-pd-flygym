# API Reference

- `AssetDatabase`: Core registry.
- `AssetReference`: Path and ID abstraction.
- `AssetCache`: LRU memory limit caching.
- `AssetLoader`: Lazy loader interface.
- `MeshAsset`, `TextureAsset`, `MaterialAsset`, `AnimationAsset`, `TrajectoryAsset`: Asset metadata definitions.
- `ProjectAssets`: Scope encapsulation.
- `ResourceManager`: Top-level facade.
- `AssetValidator`: Dependency graph and integrity checker.
- `AssetManifest`: JSON serialization.
- `AssetBundle`: Packaging primitive.
