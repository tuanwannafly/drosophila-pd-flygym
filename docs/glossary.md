# Glossary

- **Evidence JSON**: a machine-readable report produced by an authorized
  pipeline or evidence-analysis command.
- **Imported rollout**: existing trajectory/observation data supplied to a
  post-processing layer.
- **Frozen**: a checkpoint whose scientific inputs and conclusions are not to be
  changed by repository-polish work.
- **Computational proxy**: a declared simulation parameter transformation; it
  is not automatically a biological mechanism.
- **Concordance**: qualitative comparison of direction or endpoint meaning,
  not biological validation.
- **Provenance**: commit, environment, configuration, seed, input, and output
  metadata needed to understand an artifact.
- **Research repository**: source, configuration, evidence, documentation, and
  reproducibility records organized for inspection and reuse.
