# v1.0.0 - Final Drosophila locomotion phenotype framework

## 1. Summary

This release packages the canonical scientific manuscript and its final
publication artifacts as a computational Drosophila locomotion phenotype
framework. The release is an archive snapshot of the frozen repository state;
it does not introduce new simulations, evidence, or scientific claims.

## 2. Included final artifacts

- `dist/Drosophila_PD_FlyGym_Final_Report.docx`
- `dist/Drosophila_PD_FlyGym_Final_Report.pdf`
- `dist/final_report_manifest.json`

The PDF contains the manuscript figures, captions, tables, references, and
Appendices A-C. The manifest is the machine-readable artifact inventory.

## 4. Frozen evidence chain

The release preserves the completed computational evidence chain:

1. Block 8.12 pre-materialization anatomy audit.
2. Block 8.13 read-only orientation audit.
3. Milestone 8B joint materialization and post-materialization validation.
4. Milestone C unperturbed locomotion baseline.
5. Milestone D controlled perturbation framework.
6. Milestones E1-E2 parameter-response characterization.
7. Milestone E3 multi-seed robustness validation.
8. Milestone E4 qualitative literature-grounded concordance.
9. Milestone E5 computational reversibility.
10. Milestone E6 evidence-only synthesis.
11. Milestone F final document packaging.

Frozen JSON evidence and manuscript results are unchanged by this release.

## 5. Scientific scope

This release represents a computational/phenomenological framework for
simulated Drosophila locomotion. `PARTIAL_PHENOTYPE_CONCORDANCE` remains a
qualitative, direction-only literature comparison. The final candidate remains
a computational configuration for further validation.

## 6. What this release does NOT claim

This release does not claim:

- a validated Parkinson's disease model;
- dopamine equivalence or neuron-loss equivalence;
- disease-severity calibration;
- pharmacological or L-DOPA modeling;
- biological rescue;
- mechanistic disease equivalence; or
- inferential statistical significance.

Simulation outputs are not direct evidence from real Drosophila.

## 7. Reproducibility

GitHub is the source of truth. The final report is built from the canonical
manuscript with:

```bash
python scripts/build_final_report.py
```

The final artifacts can be checked against
`dist/final_report_manifest.json`. Upstream FlyGym/MuJoCo evidence requires the
documented Google Colab environment; this release package itself does not
rerun those simulations.
