# Roadmap

The historical V1 scientific roadmap is preserved in `PROJECT_CONTEXT.md` and
the release documentation. This V3-preparation migration adds repository
organization only:

1. audit current architecture and public surfaces;
2. standardize research directory anchors and templates;
3. improve documentation and reproducibility navigation;
4. preserve the frozen scientific chain while future work is separately
   authorized.

The roadmap does not authorize new simulations, perturbations, disease models,
or biological claims.
