# QA Checklist

- [ ] Scope and protected paths reviewed.
- [ ] Schema and required fields validated.
- [ ] Inputs and outputs have provenance and hashes.
- [ ] Missing, non-finite, duplicate, and malformed data behavior checked.
- [ ] Outputs are deterministic where the protocol requires it.
- [ ] Tests and Markdown validation pass.
- [ ] No generated artifact is unintentionally staged.
