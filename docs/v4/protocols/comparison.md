# Comparison Experiment Protocol

## Design

Compare named computational conditions from fresh, separately recorded states
where the existing pipeline requires it. Hold all unrelated parameters fixed;
record the one declared difference.

## Required records

- condition IDs and pair/group mapping;
- seed, duration, timestep, environment, controller, and world;
- input/output hashes and configuration hashes;
- endpoint definitions, units, missing-data behavior, and comparison method;
- validation status and known confounds.

## Interpretation

Report deltas and distributions as computational observations. Do not call a
difference disease severity, biological rescue, or mechanistic effect.
