# PD-like Computational Experiment Protocol

## Scope

This protocol is reserved for a future explicitly defined computational
condition. The label is not a validated Parkinson's disease model and must not
be mapped to dopamine, neuron loss, disease stage, severity, treatment, or
mechanism without external evidence and authorization.

## Before execution

Record the generic computational transformation, baseline configuration, seed
pairing, duration, timestep, environment, candidate identity, and preregistered
endpoints. Do not tune parameters after observing results.

## Outputs and validation

Produce paired baseline/condition manifests, raw observations, derived metrics,
finite checks, controlled-variable checks, and a conservative report. Keep
unsupported biological endpoints explicitly unsupported.
