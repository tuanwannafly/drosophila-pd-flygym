# Benchmark Experiment Protocol

## Objective

Measure software or analysis performance on declared existing inputs without
changing scientific logic.

## Method

Record operation, input size, warm-up policy, repetition count, seed, timing
clock, memory method, Python/package versions, OS, CPU, and cache state.

## Outputs

Write a benchmark manifest, raw timing rows, summary statistics, warnings, and
limitations. Do not use benchmark results as biological evidence.
