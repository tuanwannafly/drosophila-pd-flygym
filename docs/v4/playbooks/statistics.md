# Statistics Playbook

1. Define the unit of analysis and pairing before calculation.
2. Inspect missing, non-finite, duplicate, and outlier values.
3. Select descriptive or inferential procedures justified by the data and
   declared protocol.
4. Record method, seed/resampling policy, confidence settings, and assumptions.
5. Export estimates, uncertainty, effect sizes, and limitations.

No threshold is to be introduced merely to make a computational run pass.
