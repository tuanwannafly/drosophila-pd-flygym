# Publication Readiness Report

## Current status

The v1.0.0 manuscript and final report artifacts remain frozen and are covered
by the existing publication, submission, and archive packages.

## V4 gate

The V4 publication playbook is ready for future campaign outputs but does not
make those outputs publication-ready. A future package must pass evidence
traceability, figure/table/source hash, methods, results, supplementary,
reviewer, and scientific-boundary checks.

## Limitations

The repository does not claim Parkinson's disease validation, biological rescue,
dopamine equivalence, disease severity, mechanistic equivalence, or statistical
significance beyond what is explicitly supported by frozen evidence.
