# Research Readiness Report

## Status

**READY FOR PROTOCOL-DRIVEN PREPARATION; NOT YET A NEW SCIENTIFIC CAMPAIGN.**

The V4 package supplies dataset contracts, experiment protocols, analysis and
publication playbooks, SOPs, QA gates, and repository audits. It does not claim
that a future campaign has run or that new scientific evidence exists.

## Ready components

- Dataset type specifications and provenance policies.
- Healthy, PD-like computational, comparison, validation, and benchmark
  protocols.
- Import-to-publication analysis sequence.
- Figure, table, methods, results, supplementary, and reviewer gates.
- Dataset import, campaign, validation, review, publication, and maintenance
  SOPs.
- QA, reproducibility, and release checklists.

## Not ready without authorization

- A new FlyGym/MuJoCo campaign.
- Any PD-like parameter choice beyond the frozen candidate.
- New evidence JSON, biological claim, or manuscript conclusion.
- External dataset deposit or DOI not already present in the repository.

## Required next action

Approve one protocol, identify real inputs/configuration, preregister the output
path and validation semantics, then execute only in the documented environment.
