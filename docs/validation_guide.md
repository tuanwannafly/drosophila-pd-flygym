# Validation Guide

Validation has distinct layers:

- software checks: compile, unit tests, schemas, and package contracts;
- simulation checks: finite observations, controlled variables, and provenance;
- computational robustness: repeated seeds and deterministic replay;
- literature concordance: qualitative, directional endpoint mapping;
- evidence synthesis: consistency checks over frozen reports.

These layers are not interchangeable. Read the corresponding evidence JSON and
the traceability documents before making a scientific interpretation.
