# Reproducibility Guide

GitHub is the source of truth and Google Colab is the documented FlyGym/MuJoCo
execution environment. Reproduction records should include the commit, Python,
FlyGym, MuJoCo, seed, duration, timestep, configuration, output paths, and
failure logs.

The root `reproducibility/` directory contains policy and environment records.
The frozen evidence JSON and `dist/final_report_manifest.json` contain the
artifact-specific provenance and hashes.
