# Publication Guide

The canonical manuscript is `docs/report/final_report.md`. The final DOCX, PDF,
and manifest are under `dist/`; the build command is
`python scripts/build_final_report.py`. The manuscript, E6 figures/tables,
references, appendices, and reproducibility statement are indexed by the
publication and submission packages.

The final report remains a computational/phenomenological model with
qualitative `PARTIAL_PHENOTYPE_CONCORDANCE`. It is not a biological validation
claim.
