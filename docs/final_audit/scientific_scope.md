# Scientific Scope Certificate

This certificate records the scientific boundary of repository version 1.0.0.

## Preserved Scope

The repository supports a computational and phenomenological Drosophila
locomotion framework using FlyGym, NeuroMechFly, and MuJoCo. The evidence
chain covers software state, unperturbed simulation, controlled perturbations,
parameter-response characterization, multi-seed robustness, qualitative adult
walking concordance, computational reversibility, evidence synthesis, and final
report packaging.

## Frozen Candidate

- `motor_scale = 0.8`
- `coupling_scale = 0.75`

The candidate remains a computational configuration for further validation. It
is not a final or biologically validated disease model.

## Preserved Scientific Classifications

| Item | Preserved classification |
| --- | --- |
| E4 | `PARTIAL_PHENOTYPE_CONCORDANCE` |
| E5 | Computational reversibility only |
| E6 | Reproducible evidence synthesis only |
| Final report | Computational/phenomenological model |

## Explicit Non-Claims

The repository does not claim:

- biological Parkinson's disease validation
- dopamine equivalence
- neuron-loss equivalence
- disease-severity mapping
- pharmacological or L-DOPA modeling
- biological rescue
- mechanistic disease equivalence
- inferential statistical significance

Simulation outputs are not direct evidence from real Drosophila.
