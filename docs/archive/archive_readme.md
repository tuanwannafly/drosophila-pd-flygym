# Archive README

This directory prepares repository version 1.0.0 for long-term archival,
public dissemination, and future reproducibility. It is documentation only.
It does not modify scientific implementation, simulations, perturbations,
frozen evidence, manuscript content, release artifacts, notebooks, or
experimental results.

## Archive Scope

The archive package covers:

- canonical source code under `src/`
- command-line entry points under `scripts/`
- experiment and analysis configuration under `configs/`
- automated tests under `tests/`
- frozen evidence JSON under `results/`
- E6 figures and CSV tables under `results/analysis/`
- manuscript and report documentation under `docs/report/`
- final report artifacts under `dist/`
- citation, license, release notes, and community files

## Scientific Boundary

The archived repository supports a computational and phenomenological
Drosophila locomotion framework. It does not claim biological Parkinson's
disease validation, dopamine equivalence, neuron-loss equivalence,
disease-severity mapping, biological rescue, mechanistic equivalence,
pharmacological treatment response, or inferential statistical significance.
