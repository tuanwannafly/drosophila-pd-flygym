# Reviewer Checklist

- [ ] Dataset manifest and metadata are complete.
- [ ] Experiment IDs, seeds, configurations, and statuses are reproducible.
- [ ] Execution outputs are complete and finite.
- [ ] Validation profile and pass semantics are explicit.
- [ ] Figures 1-8 have source dependencies, captions, units, and hashes.
- [ ] Tables 1-5 match their evidence and preserve missing values.
- [ ] Supplementary assets and references are complete.
- [ ] Artifact integrity and checksum manifests pass.
- [ ] No computational result is described as biological validation.
