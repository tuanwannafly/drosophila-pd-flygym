# 138. Publication Skeleton

The editable planning skeleton is under
[`paper/healthy_baseline/`](../../paper/healthy_baseline/). The existing
`research/publication/healthy_baseline/` directory remains the output-layout
anchor from V5. These are separate from the frozen manuscript and do not
replace it.

The six skeleton files contain headings and evidence gates only:

- `methods.md`
- `results.md`
- `discussion.md`
- `limitations.md`
- `supplementary.md`
- `references.md`

They intentionally contain no new results, conclusions, biological claims, or
references.
