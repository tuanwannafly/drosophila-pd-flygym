# Research Guide

Use the repository as a chain:

```text
configuration -> authorized execution or imported artifact -> analysis -> validation -> report
```

Record provenance, seed, environment, and input/output paths. Keep raw data
outside Git unless it is explicitly curated. Use the session inventory,
traceability graph, scientific endpoint mapping, and reproducibility records to
identify what is measured and what remains unsupported.

No computational phenotype should be called a biological disease model without
external evidence and explicit authorization.
