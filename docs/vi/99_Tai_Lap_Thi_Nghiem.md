# Tái lập thí nghiệm

GitHub là nguồn chuẩn; Google Colab là môi trường thực thi FlyGym/MuJoCo đã
được ghi nhận. Dùng Python 3.12, FlyGym 2.1.0 và MuJoCo 3.9.0 khi chạy các
milestone cần simulation. Kiểm tra đúng commit và cấu hình trước khi chạy.

Mỗi kết quả cần lưu metadata môi trường, seed, lệnh, đường dẫn output và trạng
thái kiểm định. Không ghi đè evidence đóng băng.
