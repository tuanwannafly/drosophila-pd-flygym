# User Workflow

1. Mo tab `Datasets` va chon `Load dataset JSON`.
2. Chon rollout JSON hoac `viewer_pose.json` hop le.
3. Mo tab `Viewer` de xem pose, reset camera, hoac focus selection.
4. Keo Timeline de dong bo Viewer, Inspector, COM, skeleton va behavior.
5. Mo `Analysis` de xem chart khi rollout FlyGym da co statistics.
6. Mo `Validation`, `Reports`, `Publication` hoac `Plugins` de xem artifact
   hien co.

Neu khong co du lieu phu hop, giao dien hien thi trang thai trong thay vi tao
du lieu gia. Cac bao cao va ket luan khoa hoc van phai duoc doc tu artifact
nguon da xac minh.
