# Câu hỏi thường gặp

**Hệ thống có chạy FlyGym khi mở dashboard không?** Không.

**Nhãn Candidate/PD có phải chẩn đoán không?** Không; đó là computational/data
label.

cùng metadata/provenance phù hợp.

**Có tạo dữ liệu demo để lấp thiếu không?** Không trong pipeline khoa học.
