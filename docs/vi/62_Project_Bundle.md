# 62. Project Bundle

Project Bundle đóng gói metadata dataset, analysis report, chart references,
validation report, notebook entries, publication assets và artifact references
đã có. Manifest ghi các section và số artifact; checksum giúp nhận diện bundle.

Bundle không chứa rollout mới được tạo tự động và không khẳng định tính hợp lệ
sinh học. Trước khi chia sẻ, cần kiểm tra source rollout, provenance, version
và scientific scope.
