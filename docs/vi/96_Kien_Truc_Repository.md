# Kiến trúc Repository

Repository gồm package Python trong `src/`, cấu hình trong `configs/`, CLI
trong `scripts/`, kiểm thử trong `tests/`, ứng dụng Web trong `web/`, notebook
lịch sử trong `notebooks/` và tài liệu trong `docs/`.

Đường nghiên cứu đóng băng và nền tảng V2 bổ sung được giữ riêng. Các thư mục
`research/`, `templates/` và `reproducibility/` là điểm tổ chức tài liệu, không
tự tạo rollout hay dữ liệu khoa học.

Xem [bản đồ kiến trúc](../repository_architecture.md) để biết chi tiết.
