# 71. Developer Toolkit

Developer Toolkit dùng các explorer hiện có để cung cấp project doctor,
dependency inspector, architecture browser, API explorer, test explorer và
performance scope.

Ví dụ:

```bash
python scripts/research_automation_cli.py developer architecture-browser
python scripts/research_automation_cli.py developer dependency-inspector
```

Các báo cáo là static inventory hoặc caller-supplied benchmark metadata.
