# Web Demo

## Chay local

```text
python scripts/run_web_demo.py --host 127.0.0.1 --port 8000
```

Mo URL duoc in trong terminal. Co the tu dong mo trinh duyet bang:

```text
python scripts/run_web_demo.py --open
```

Server chi phuc vu thu muc `web/`. No khong chay FlyGym, khong chay MuJoCo,
va khong tao rollout.
