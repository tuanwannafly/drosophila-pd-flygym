# 58. Workspace và Layout

`WorkbenchLayoutManager` lưu layout có tên, trạng thái dock, split view, kích
thước panel, panel floating và fullscreen. Bốn layout mặc định là Analysis,
Publication, Comparison và Validation.

Layout là trạng thái trình bày, không phải dữ liệu khoa học. Có thể chọn,
lưu, khôi phục hoặc reset layout mà không thay đổi rollout, simulation hay
evidence.
