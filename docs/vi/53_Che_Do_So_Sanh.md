# 53. Chế độ so sánh

Comparison Viewer dùng các rollout đã import vào Experiment Workspace. Healthy,
Candidate và các nhãn khác là nhãn điều kiện tính toán; chúng không khẳng định
tương đương sinh học.

Viewer hỗ trợ các cột đồng bộ, slider frame, trajectory overlay và summary
differences. Chỉ các channel có trong rollout mới được vẽ. Dữ liệu thiếu được
hiển thị là không khả dụng thay vì thay bằng dữ liệu giả.
