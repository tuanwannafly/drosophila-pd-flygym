# 63. Dataset Catalog

Dataset Catalog đăng ký các file hoặc thư mục dataset đã tồn tại. Mỗi entry có
UUID logic, tên, version, source, SHA-256, ngày import, tags, species,
experiment type, license, citation và manifest.

Catalog hỗ trợ search, filter, grouping, version history và integrity
verification. Catalog không copy hoặc tạo rollout nếu người dùng không yêu
cầu rõ ràng.
