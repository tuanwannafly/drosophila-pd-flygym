# 57. Dataset manifest

Manifest luu dataset ID, loai, phien ban semantic, trang thai, entries,
checksum, metadata, provenance va gioi han khoa hoc. `DatasetVersion` yeu cau
dang `MAJOR.MINOR.PATCH`; `DatasetChecksum` yeu cau SHA-256 64 ky tu.

Manifest la nguon su that cho cac file du lieu. File khong duoc khai bao khong
duoc tu dong xem la rollout hop le.
