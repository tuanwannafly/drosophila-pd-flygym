# 65. Reproducibility Center

Reproducibility Center ghi git commit, branch, tag, Python, package versions,
OS, CPU, configuration hash, dataset checksums, output hashes, seed và
environment metadata.

Manifest được tạo từ inputs và outputs do caller cung cấp. Nó không tự rerun
FlyGym/MuJoCo và không khẳng định kết quả sinh học.
