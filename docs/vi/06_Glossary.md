# 7. Glossary

| Thuật ngữ | Giải thích |
|---|---|
| Rollout | Chuỗi quan sát theo thời gian từ một lần chạy hoặc một nguồn dữ liệu. |
| Trajectory | Quỹ đạo vị trí của một body, COM hoặc channel theo frame. |
| Workspace | State trung tâm của web editor/viewer. |
| QC | Quality control, kiểm tra thiếu dữ liệu, NaN, Inf, range và consistency. |
| Feature | Đại lượng được trích xuất từ rollout, ví dụ speed hoặc heading. |
| Bootstrap | Lấy mẫu lại để ước lượng phân phối thống kê hoặc khoảng tin cậy. |
| Permutation test | Kiểm định dựa trên việc hoán vị nhãn hoặc quan sát. |
| Effect size | Độ lớn khác biệt, không đồng nghĩa với ý nghĩa sinh học. |
| Manifest | Metadata mô tả plugin, version, dependency và capability. |
| Hook | Điểm sự kiện nơi plugin có thể nhận payload do host gửi. |
| Capability | Nhóm quyền/chức năng mà plugin khai báo. |
| Plugin context | API giới hạn mà host cung cấp cho plugin; không phải Workspace nội bộ. |
| Evidence | Artifact kết quả đã ghi nhận; không được tự diễn giải vượt phạm vi. |
| Provenance | Thông tin nguồn, commit, cấu hình, môi trường và checksum. |
