# Roadmap V3

Chương trình V3 trước hết chuẩn hóa repository nghiên cứu: bản đồ kiến trúc,
template, reproducibility, developer experience và documentation hub.

Đây là roadmap kỹ thuật, không phải ủy quyền thêm simulation, perturbation,
thuật toán Parkinson hoặc tuyên bố sinh học. Mọi giai đoạn nghiên cứu mới cần
được phê duyệt và ghi provenance riêng.
