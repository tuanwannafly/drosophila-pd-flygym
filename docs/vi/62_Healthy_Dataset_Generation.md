# Healthy Dataset Generation

Notebook 05 tạo một rollout Healthy computational có giới hạn bước và lưu
vào `datasets/healthy/Healthy_001/`. Package gồm các file export, metadata,
logs, manifest và một NPZ canonical tương thích với pipeline execution hiện
có.

Không có dữ liệu giả được tạo. Nếu FlyGym hoặc controller không sẵn sàng,
notebook ghi lỗi và không tuyên bố dataset hợp lệ.
