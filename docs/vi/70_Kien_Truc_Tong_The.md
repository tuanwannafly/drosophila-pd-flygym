# Kien truc tong the

Repository gom bon lop chinh: pipeline khoa hoc tinh toan, lop quan ly artifact
va workflow, Fly Studio Python, va Web Viewer. `src/drosophila_pd` la package
Python; `web/` la ung dung trinh duyet; `docs/` la tai lieu va provenance.

V1 khoa hoc, evidence, manuscript, notebook va release artifact van giu
nguyen. Cac lop V2 xu ly artifact da import va khong tu tao ket luan sinh hoc.

## Nguyen tac

- GitHub la source of truth.
- Manifest la diem truy vet cua dataset va artifact.
- FlyGym/MuJoCo chi chay trong moi truong duoc phe duyet.
- Ket qua mo phong khong phai du lieu tu ruoi that.
