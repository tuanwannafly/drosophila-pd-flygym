# Hướng dẫn người dùng

1. Mở `web/index.html` qua GitHub Pages hoặc web server tĩnh.
2. Import rollout FlyGym đã tồn tại.
3. Dùng Experiment/Dataset để lọc và chọn dữ liệu.
4. Xem Digital Fly, timeline, analytics và validation khi reference data có sẵn.
5. Xuất report/publication asset từ dữ liệu và metadata đã nạp.

Không có bước nào trong giao diện tự chạy simulation.
