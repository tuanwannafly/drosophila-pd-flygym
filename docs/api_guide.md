# API Guide

Start with [public_api.md](public_api.md), then follow the package-specific
guides under `docs/v2/`. The `src/drosophila_pd` package is installed through
the `src` layout; no `PYTHONPATH` override is required.

The source module and package `__init__.py` files are the authority for exact
signatures. Generated release inventories are useful navigation aids but do not
replace source review.
