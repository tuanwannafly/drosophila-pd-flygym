# Rationalization Archive Index

This directory is an index for future repository cleanup. It intentionally
does not copy or move frozen scientific files. Existing archival material is
maintained under [`docs/archive/`](../docs/archive/archive_readme.md).

Candidate documents and modules remain in their original locations until
imports, links, tests, and provenance references have been checked. See
[`rationalization_manifest.csv`](rationalization_manifest.csv) and the
[repository audit](../docs/architecture/repository_audit.md).
