# Research Workspace

This directory is the V3-preparation organizational root for research-facing
artifacts. It contains no generated rollout data in the repository snapshot.
Use the named subdirectories for explicitly curated campaign plans, datasets,
reports, figures, publication material, supplementary material, benchmarks,
validation, reproducibility records, templates, and examples.

Every future artifact should carry a provenance record and should be reviewed
against the frozen scientific boundary before it is version-controlled.
