# Reviewer Checklist

- [ ] The package is marked planning-only and contains no rollout.
- [ ] `PD_001` through `PD_100` appear exactly once.
- [ ] Seeds, configurations, expected outputs, and validation profiles are
      recorded for every planned row.
- [ ] An approved computational configuration exists before execution.
- [ ] Manifest, metadata, trajectory declarations, and checksums agree.
- [ ] Missing, duplicate, non-finite, and unsupported data are reported.
- [ ] Reports distinguish computational condition from biological disease.
- [ ] No candidate is called validated Parkinson's disease.
- [ ] Figures, tables, supplementary files, and provenance are complete before
      publication review.
