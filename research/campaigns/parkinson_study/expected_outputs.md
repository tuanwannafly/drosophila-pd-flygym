# Expected Outputs

Each future experiment is expected to use the existing output contract:

```text
pd/<experiment-id>/
  rollout/
  measurements/
  analysis/
  statistics/
  validation/
  reports/
  metadata/
  manifest.json
  checksum.json
```

Expected artifacts are computational reports and declared data products only.
No output is generated by Project B. A missing dataset produces
`WAITING_DATASET`; it must not produce an empty scientific result.
