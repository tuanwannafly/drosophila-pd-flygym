# Healthy Baseline Validation Inventory

The future validation package should preserve the distinction below.

| Validation class | Evidence | Meaning |
| --- | --- | --- |
| Schema | Manifest and metadata schema checks | Contract compliance |
| Integrity | File existence, byte size, SHA-256, duplicates | Data/package integrity |
| Rollout quality | Frame count, finite values, trajectory consistency | Computational data quality |
| Reproducibility | Seed, configuration, environment, repeated outputs | Software repeatability |
| Scientific boundary | Report and claim review | Prevents overclaiming |

These checks do not validate Parkinson's disease biology and do not make a
Healthy rollout biological evidence.
