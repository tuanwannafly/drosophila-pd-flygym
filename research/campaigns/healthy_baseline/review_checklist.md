# Healthy Baseline Review Checklist

Planning-only reviewer gate. Mark items only after a real dataset exists.

- [ ] Dataset ID, type, version, source commit, license, and citation are valid.
- [ ] `Healthy_001` through `Healthy_100` are uniquely represented where
      planned.
- [ ] Seeds and configuration paths match `experiment_matrix.csv`.
- [ ] Manifest entries, metadata, and checksums agree.
- [ ] Required trajectory files exist and frame counts are valid.
- [ ] Missing, duplicate, NaN, and infinite values are reported.
- [ ] Analysis, validation, and report artifacts are traceable.
- [ ] Figures 1-8 and Tables 1-6 have source and provenance records.
- [ ] No claim exceeds computational evidence or the manuscript boundary.
- [ ] Reviewer package and archive inventory are complete.
