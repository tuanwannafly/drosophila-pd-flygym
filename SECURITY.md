# Security Policy

## Supported Versions

Release v1.0.0 is frozen. Security-relevant reports for the current repository
state are welcome, especially issues affecting reproducibility, dependency
safety, command execution, artifact handling, or accidental disclosure of local
paths or credentials.

## Reporting a Vulnerability

If GitHub private vulnerability reporting is enabled for this repository, use
that channel. Otherwise, contact the repository maintainer through GitHub with a
minimal public issue that does not disclose exploit details, credentials, or
sensitive paths.

Please include:

- affected file or workflow;
- expected behavior;
- observed behavior;
- reproduction steps that do not expose secrets;
- suggested mitigation, if known.

## Scientific Scope

This repository is research software, not a medical device, diagnostic tool, or
validated biological model. Security reports should not be framed as clinical
or biological validation findings.
